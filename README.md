# DoaMaisEduca — API RESTful (ODS 4: Educação de Qualidade)

## 📌 Sobre o Projeto

O **DoaMaisEduca** é uma API RESTful desenvolvida em **Node.js** com **Express** criada para apoiar o **ODS 4 (Educação de Qualidade)** da ONU.

### 🎯 Problema e Solução

- **Problema:** O acesso desigual a materiais escolares adequados compromete a permanência e a qualidade do aprendizado de estudantes em situação de vulnerabilidade.
- **Solução:** A API atua como uma plataforma centralizada para gerenciar e catalogar doações de materiais pedagógicos e equipamentos escolares, conectando doadores às necessidades da comunidade.

---

## 🛠️ Tecnologias Utilizadas

- **Node.js** (Ambiente de execução)
- **Express** (Framework para API REST)
- **REST Client** (Testes de endpoints via `requisicoes.http`)
